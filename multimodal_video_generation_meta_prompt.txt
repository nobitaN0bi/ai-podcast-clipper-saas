---[ CONSISTENCY PRESERVATION PROTOCOL ]---

CRITICAL: SCENE COHERENCE ALGORITHM

To ensure visual consistency between starting and ending scenes across
multiple generative clips, implement this multi-phase approach:

PHASE 1: ANCHOR FRAME EXTRACTION
├── Extract last frame of Clip N using FFMPEG/CV2
├── Upload frame to temporary S3 storage
├── Generate signed URL for fal.ai image-to-video input

PHASE 2: SEED-LOCKED GENERATION
├── Use IDENTICAL seed values for related scene generations
├── Maintain consistent negative_prompt across sequence
├── Lock aspect_ratio, resolution for the entire series

PHASE 3: STYLE CONSISTENCY PROMPTING
├── Embed style tokens in ALL prompts: "[STYLE: <descriptors>]"
├── Include character/subject descriptions in every prompt
├── Reference previous scene elements explicitly

EXAMPLE CONSISTENCY WORKFLOW:
```python
class ConsistentVideoGenerator:
    def __init__(self, master_seed: int = 42):
        self.master_seed = master_seed
        self.style_tokens = None
        self.character_descriptions = []
        
    def set_visual_identity(self, style: str, characters: list):
        """Lock visual identity for entire session."""
        self.style_tokens = style
        self.character_descriptions = characters
    
    def build_consistent_prompt(self, scene_action: str) -> str:
        """Inject consistency markers into prompt."""
        return f"""
        [STYLE: {self.style_tokens}]
        [CHARACTERS: {', '.join(self.character_descriptions)}]
        {scene_action}
        Maintain visual continuity with previous scene.
        """
    
    def generate_intro_scene(self, prompt: str) -> dict:
        """Generate opening scene, save last frame."""
        result = fal.subscribe("fal-ai/hunyuan-video", arguments={
            "prompt": self.build_consistent_prompt(prompt),
            "seed": self.master_seed,
            "aspect_ratio": "9:16",  # Vertical for shorts
            "resolution": "720p",
            "num_frames": 129,
            "num_inference_steps": 35
        })
        # Extract and store last frame for next clip
        last_frame = self._extract_last_frame(result["video"]["url"])
        return {"video": result, "anchor_frame": last_frame}
    
    def generate_continuation(self, anchor_frame_url: str, prompt: str) -> dict:
        """Continue from previous scene's last frame."""
        return fal.subscribe("fal-ai/hunyuan-video/image-to-video", arguments={
            "image_url": anchor_frame_url,
            "prompt": self.build_consistent_prompt(prompt),
            "seed": self.master_seed,
            "i2v_stability": True,  # Reduce visual drift
            "aspect_ratio": "9:16",
            "resolution": "720p"
        })
    
    def generate_outro_matching_intro(self, intro_frame_url: str, prompt: str):
        """Generate ending that mirrors intro for loop effect."""
        return fal.subscribe("fal-ai/hunyuan-video/image-to-video", arguments={
            "image_url": intro_frame_url,
            "prompt": self.build_consistent_prompt(f"{prompt} - returning to opening composition"),
            "seed": self.master_seed,
            "i2v_stability": True
        })
```

---[ ERROR HANDLING & RETRY LOGIC ]---

```python
import time
from tenacity import retry, stop_after_attempt, wait_exponential

@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=4, max=60))
def safe_video_generation(prompt: str, params: dict) -> dict:
    """Robust video generation with exponential backoff."""
    try:
        result = fal.subscribe("fal-ai/hunyuan-video", arguments={
            "prompt": prompt,
            **params
        })
        return result
    except Exception as e:
        if "rate_limit" in str(e).lower():
            time.sleep(30)
        raise e
```
